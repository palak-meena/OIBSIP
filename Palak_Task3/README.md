
# Random Password Generator

## Description
This Python project generates a random password based on the length entered by the user.

## Features
- Generates random passwords.
- Includes uppercase and lowercase letters.
- Includes numbers and special symbols.
- Displays an error if the password length is zero or negative.

## Technologies Used
- Python
- Programiz Online Compiler
- GitHub

## How to Run
1. Run the Python program.
2. Enter the desired password length.
3. The generated password will appear on the screen.
