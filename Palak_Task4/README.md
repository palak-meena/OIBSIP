Task 4: Basic Weather App

Description

This is a simple Python-based Weather App that fetches current weather information for a user-entered city using the Open-Meteo API.

Features

- Enter a city name to get its weather report.
- Displays current temperature in Celsius.
- Shows feels-like temperature.
- Displays humidity percentage.
- Shows wind speed in km/h.
- Uses an API that does not require an API key.

Technologies Used

- Python
- Open-Meteo Geocoding API
- Open-Meteo Weather API
- "urllib" and "json" Python modules

How to Run

1. Install Python 3.
2. Save the program as "basic_weather_app.py".
3. Run the file using:

python basic_weather_app.py

4. Enter a city name when prompted.
5. The app displays the current weather information.
