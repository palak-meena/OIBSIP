
BMI Calculator

Project Description

A simple Python program that calculates Body Mass Index (BMI) using weight and height.

Features

- Takes weight in kilograms.
- Takes height in meters.
- Calculates BMI.
- Displays the BMI category.
- Handles invalid numeric input and non-positive values.

Formula

BMI = Weight (kg) / Height (m)²

How to Run

Run "bmi_calculator.py" using Python and enter your weight and height when prompted.

Technology Used
